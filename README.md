# Desafios de Lógica de Programação

Este repositório contém soluções para desafios de lógica de programação e manipulação de dados. Os problemas abordam cálculos matemáticos, análise de dados e manipulação de strings e arquivos JSON.

## Estrutura do Teste

1. **Soma com Loop**  
   Calcular a soma de números consecutivos.

2. **Fibonacci**  
   Verificar se um número pertence à sequência de Fibonacci.

3. **Faturamento Diário**  
   Analisar dados para encontrar:
   - O menor valor de faturamento ocorrido em um dia do mês.
   - O maior valor de faturamento ocorrido em um dia do mês.
   - O número de dias no mês em que o valor de faturamento diário foi superior à média mensal.

4. **Percentual por Estado**  
   Calcular a contribuição percentual de cada estado no faturamento total mensal da distribuidora.

5. **Inversão de String**  
   Inverter uma string sem usar funções prontas, como `reverse`.

## Requisitos

- **Linguagem**: C# (ou outra de sua escolha).
- **Framework**: .NET 8 (para soluções em C#).
- **Entrada e Saída**: Via console.
- **Manipulação de Arquivos**: Uso de JSON para o desafio 3.

## Como Executar

1. Clone este repositório:
   ```bash
   git clone github.com/VictorMoraesSantos/Teste-Desenvolvedor-Target-Sistemas.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd Teste-Desenvolvedor-Target-Sistemas
   ```

3. Compile e execute os programas utilizando o .NET SDK:
   ```bash
   dotnet run
   ```
